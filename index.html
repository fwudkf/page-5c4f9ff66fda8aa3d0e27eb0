从订阅到连接

操作说明只保留能独立完成的步骤。下载入口以本页客户端模块为准，不要从来路不明的网盘或转载帖获取安装包。

一、确认方案并保存订阅

在套餐区域对照流量与同时在线设备数，开通后立即把订阅链接存到只有自己能看到的位置。链接相当于钥匙，公开粘贴等于把访问权交出。

二、按系统安装客户端

Windows、macOS、iOS、Android 与常见路由环境各自对应不同客户端。先装再导入，避免把订阅填进错误的软件。

三、导入、更新、连接

  1. 打开客户端，选择订阅或 URL 导入，完整粘贴链接。
  2. 更新节点列表，观察是否出现可选择的线路。
  3. 选一条延迟可接受的节点连接，再用浏览器访问目标站点。
  4. 若失败，先核对系统时间、通知权限、是否有其他代理占用端口，再换一条节点。

常见问题

这一块是快柠檬本页的重点：把第一次配置最容易问到的事项写成可展开问答。先扫问题标题，再打开与自己情况对应的一条即可。

快柠檬是机场、VPN 还是加速器？

在使用层面，快柠檬按机场订阅来组织线路，再用各平台客户端充当梯子或网络加速器。你拿到的是订阅链接，而不是只能在一个封闭 App 里点开关的单一通道。本页同时覆盖订阅说明与客户端下载，是为了让这两步对得上。

完全没有网络基础，能不能自己完成？

可以。顺序保持「开通并保存链接 → 在本页下载对应客户端 → 粘贴导入 → 选节点连接」。只要链接是完整复制的，大多数失败其实来自漏字符、系统时间不准，或电脑上还开着另一个代理软件。

客户端应该选哪一个？有没有通用安装包？

没有真正的「一个包打天下」。手机与电脑系统不同，客户端也不同。请只使用本页客户端模块给出的入口，并核对自己的系统名称。搜索引擎里同名软件很多，混装后常见症状是能打开软件却更新不到节点。

多台设备可以一起用吗？订阅能分享吗？

可以在自己的设备上分别导入同一条订阅，但同时在线数量以套餐模块标明的台数为准。订阅不要发到群、网盘或社交动态。一旦怀疑泄露，应在服务侧重置订阅，并让每台设备重新更新。

显示已经连接，网页却打不开或特别慢，怎么办？

先换一条节点，再检查浏览器是否还开着别的代理扩展。部分环境需要在客户端里切换系统代理或规则模式。若只有个别网站失败，多半是分流规则问题；若全部失败，优先排除本地防火墙和重复代理。

快柠檬官网会公布评分、节点数量或测速榜吗？

不会。本页只提供品牌简介、场景、操作说明、套餐模块、客户端下载与常见问题，不编造评价、节点规模或速度排行。需要核对的只有套餐模块里的标价与权益，以及客户端是否来自本页入口。
